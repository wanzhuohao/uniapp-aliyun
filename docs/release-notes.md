## 发布元信息模板

| 项 | 值 |
|------|------|
| 公网地址 | （发行后在 HBuilderX 控制台获取 uniCloud-aliyun 前端网页托管 URL） |
| 发布时间 | （发行操作完成的日期时间） |
| 源码基线 | master@（提交哈希） |
| HBuilderX compilerVersion | （发行所用 HBuilderX 的编译器版本号） |
| 主资源名 | （发行后生成的入口 HTML 文件名，通常为 index.html） |
| 托管环境 | uniCloud-aliyun 前端网页托管（BSPAPP CDN） |
